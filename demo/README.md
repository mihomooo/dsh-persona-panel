# persona-plugin 原型

这是「记忆」插件的**能点的静态原型**，不是插件。数据全是假的、存在内存里，刷新就复位。

## 打开

双击 `demo/index.html`（Edge / Chrome 都行）。

- 默认先弹「首启」→ 点「开始」进面板。
- 想跳过首启：地址后面加 `?skip=1`。

## 现在能点什么

| 位置 | 能做什么 |
|---|---|
| 左栏工作区 | 切换；`ds` 上的 `↔1`＝它的人设被 1 个工作区共用；`生活` 上写「共用自 ds」；悬停出现 `×` → 删工作区（只撤指针，记忆不跟着走） |
| 人设卡 | 悬停大类 → 编辑 / 删 / 悔一步；点一条 → 右栏详情，强度五格可直接点 |
| ＋加大类 / 加补充 | 「加什么」可切大类或人格补充；**词库给一排可点的词，也能直接写新词**；补充可勾「标为硬约束」，带红色「硬」小标、排最前 |
| 粘贴一整段人设… | 粘一段话 → 「拆一拆」→ 拆成**大类**（可调强度）+ **人格补充**（原样、带「原样」标）→ 勾选后落盘 |
| 画像 | 只删不改（这是你的印象，不是你的自述） |
| 事件 | 「演示：我弹一条询问」→ 收下 → 进「待你决定」→ 记住 → 可改状态 |
| 右下 复制… | 选来源、勾类别、选「副本复制 / 共生转移」，先出预览再落盘；已有共用的可「切断共生」 |
| 右下 归档… | 两步确认（第二步按钮换位置），收进归档，设置里能恢复 |
| 设置里的 无主记忆 | 删掉的工作区若没人共用，记忆落到这里；可「接回」或「永久删除」（两次确认） |
| 齿轮 | 设置：称呼 / 名字 / 四挡 / **3×2 开关表**（启用 × 记录）/ **默认词库** / 归档恢复 |

关掉某类的「记录」后：页签旁出现「只读」——还记得、还注入，但不再新增。

**首启弹窗**现在真给三个勾选框：关掉的那个在面板里就不存在（不显示、不注入、不记）。

## 词库是什么、不是什么

- 是：增大类时给你一排可点的词，省打字；列表在设置里可改（空格或逗号分隔）。
- 不是：一个封闭枚举。人格不只依赖词库——聊天里长出「护短」「爱较真」这类词，直接写在输入框里就行。

## 归纳走哪条路

走 **A**：我在会话里读你粘的那段话，拆成条目再调工具落盘，不额外调模型。拆的时候只分两桶——

- **大类**：可以归纳、有强度、之后按相处上下调。
- **人格补充**：原样保留，不概括。像「不要用 emoji」「别问我需不需要继续」这类约束也放这里，落盘后带一个「原样」小标。

## 「硬」是什么

人格补充里有些不是性格，是规矩：`不要用 emoji`、`别问我需不需要继续`。它们改一个字意思就变，所以不给归纳、只给原样保留，另外可以标一个红色「硬」小标 —— 只影响**注入顺序**（排补充最前面），不换桶、不影响删除和编辑。

## 删工作区，记忆会怎样

数据是 `store`，工作区只是指向它的指针。所以：

- **删子体** → 母体毫发无损（母体从来没被反向依赖）。
- **删母体、还有别人共用** → 那个还活着的工作区继承同一份数据，一条不少。
- **删母体、没人共用了** → 记忆进「无主记忆」（设置里），不在列表里出现，**不当场删**；要删得点「永久删除」，两次确认。
- 同一个工作区名重新开出来，**不自动接回旧账** —— 默认是空的，要接回就手动「接回」。

原型里这些都能点：左栏悬停 `×`、设置里的「无主记忆」。

## 文件

- `demo/index.html` — 原型本体（单文件，无依赖）

- `docs/preview.png` — 线框长图
- `demo/shot-*.png` — 原型截图
