# 0.6.0 — 人格档案

这一版把「记忆」从一个工作区搬到可以流转的档案上。

## 新：人格档案（右上角「人格档案」）

一行一份档案，一行写着它来自哪几个工作区（共生的一组算一份，只列最近用过的三个），以及脾气/印象/事件/日记各多少条。

- **覆盖并替换…**：把这份档案整套盖到某个工作区头上。目标非空时先问「里面有东西，是否归档」——归档之后旧的那套才变成一份已归档档案，不会凭空消失；空工作区直接替换，不留残影。
- **存一份快照**：工作区那张卡片是实时镜像，工作区一改它就跟着改。点这里把它冻成一份独立副本，之后工作区再怎么变都碰不到它。
- **借记忆也会先问**：从别的工作区「副本复制」或「共生转移」过来时，只要当前工作区不是空的，都会先问「先存一份已归档档案再继续？」——点「归档并继续」把旧的那份留进人格档案，点「直接继续」才真的不备份。
- **共生的一组算一份**：几个工作区共用一个脑子的，只出现一张卡片，右侧标着「共生 N ▸」，点开就是共用的那几个工作区名。切断之后各算各的。
- **已归档**：归档或删工作区留下的那套记忆，来源照旧写着母体。它只能用一次——被拿去替换一次之后就变成普通档案，之后只是备份。
- **导出到桌面…**：写一份 `.json`，能被「导入人设」读进去，也能被「导入档案文件…」装成新档案。
- **导入档案文件…**：直接装成一份档案，不碰任何工作区。
- **永久删除**：两下。第一下只是改成「确认删除」。

## 改：无主记忆并入档案

设置里的「无主记忆」段整段撤掉，入口统一到人格档案；原来那套「找回」的字还在归档确认框里，找回仍然是合并，不是覆盖。

## 改：回忆能「大概」对上

`persona_recall` 的 `query` 不再要求字符逐个命中：词里的字只要按顺序出现在句子里、且跨度不太散，就算一条「大概」的命中，结果里会注明「其中 N 条是大概对上的」。精确命中的永远排在前面。

## 新：事件的目录视图

`persona_recall({ depth: "index" })` 现在同时给事件的月份目录（`2026-10（12 条 · 有★）`），末尾提示「先看月份，再按日期挑」。日记目录照旧。

## 修：两处冒烟里露出来的毛病

- 档案卡片在只有一处来源、且来源跟名字一样时，不再把同一句话写两遍（`乙工区 / 来自「乙工区」`）。
- 设置页会继承模板：只改过一两个键的工作区，不再显示空的「我该怎么称呼你 / 我给自己起的名字」，也不会把「全自动」显示成「全手动」。显式清空的称呼仍然是空的。

## 升级

数据在 `~/.dsh/persona-panel/`，直接覆盖安装即可；老库没有 `profiles` 字段也能跑（第一次打开档案面板时就地补上）。
