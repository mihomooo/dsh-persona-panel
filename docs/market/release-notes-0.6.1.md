# 0.6.1 — 关掉就是关掉

## 修：设置里关掉的类，面板当场就不显示了

之前在看「日记」的时候打开设置、把日记的「启用」和「记录」都关掉，日记栏还留在那儿，条目也还在——要等下一次刷新才消失。

现在切换开关会立刻重读一遍面板：关掉哪个，哪个栏就下去；四类全关，面板只写一句「这个工作区三类都关着，所以这里没有内容」（日记算第四类，一起关的时候也走这句）。

## 修：归档提示的「×」是永久的

那个「这个工作区的 N 条记忆在 X 时被归档了」的提示，以前关掉只在这一次面板里有效——切个标签、重开面板，它又回来了。

现在关一次就记住：这条提示不会再出现。档案本身没动，还在「人格档案」里标着「已归档」，能导出、能拿来覆盖别的工作区，也能合并回这个工作区。

## 放宽：日记与事件的写法

原来那句「判断一下该不该记」被读成了心里要先打一遍分：值不值得、算不算、要不要。有人会把这套判断写到嘴上。

现在改成：

- 想记就记，不用请示，也不许在回复或思考里列「这条值不值得记」的清单；
- 日记不是作业，没有配额，不必深刻，一句想留的话就够；
- 事件也算小事：不只是承诺和里程碑，一件不想弄丢的小事同样可以留。

## 升级

覆盖安装即可，数据仍在 `~/.dsh/persona-panel/`。老库没有 `dismissed` 字段也能跑。
