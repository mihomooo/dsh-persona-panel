## 0.4.9

一个洞：**归档只进不出**。

- 面板「归档…」会把这个人设、画像、事件整份收进「无主记忆」，但设置页里那几行只有「永久删除」——宿主早就有 `restoreArchive`，界面一直没给入口。现在每行多一个「找回…」，点开再确认一次，并回当前工作区。
- 找回是**合并**不是覆盖：归档之后新写的条目留着，同 id 的只留一份；重复点不会写出两份。
- **找得到才算有找回**。归档之后，被归档的工作区顶部直接显示一条横幅「这个工作区的 N 条记忆在某时被归档了」，旁边就是「找回」；设置里的「无主记忆」补了一行说明，写清「找回…」并回当前工作区、「永久删除」不可逆；归档确认框里也点明了这两条路。
- 新增 `demo/archive-test.mjs`（19 项）：归档后清空、无主记忆计数、带着原工作区路径、新条目存活、找回不重不漏、二次找回是空操作、客户端确实发了 `restoreArchive`、横幅与两处文案路径都在。

顺带把 0.4.8 那条「记忆文本压平」的检查补齐到十个套件，全绿。
