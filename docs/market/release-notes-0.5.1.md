# v0.5.1

「导入会话记录」换成「回忆并写入」：不再把对话导出成文件让模型去读，而是直接给它一条回忆的指令。

## 为什么换

上一版是把工作区的会话记录写成一份 `imports/*.md`，提示词再要模型「读这个文件、回忆你自己」。三个问题：

- **多一道手**：先扫会话、解 zstd、写成 32 万字的文件，再让模型分段读回来。每一次都是成本。
- **读成了别人的材料**：一份讲对话 transcripts 的文档，模型很容易当成「要总结的聊天记录」，而不是「我自己的过去」。提示词里写多少遍「别总结对话」都是在跟文件的语气较劲。
- **跨会话其实读不全**：默认只收最近 20 场，更早的直接丢，而用户以为「读取会话记录」就是全部。

## 现在怎么做

点「回忆并写入…」，面板给**这个工作区正在开着的会话**发一条指令：

- 停下别的事，做一次回忆；**不要复述我们聊过什么，也不要总结这段对话**。
- 四类各写：`kind=self` 脾气（label 一两个词、intensity 1–5）、`kind=self` + `hard=true` 不可改的规矩（原话照抄）、`kind=user` 对这个人的画像、`kind=event` 约定与时刻（约好的带 date）。
- 动手前先 `persona_recall` 看已经有什么：写过的别重复，要改的直接改。
- 第一人称、短句、具体；宁可少写三条也不写泛泛的摘要。
- **手上没有对话就不许编**：直接说「我手上没有这段记忆」然后停。

会话开着 → 当场执行；没开着 → 面板直接说「先在这里开一个会话，再点一次」，不再静默排队等下一次开口。
