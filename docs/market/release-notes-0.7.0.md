# v0.7.0 — 让它自己想起来

这一版只做一件事：**把「记录」从指望模型的自觉，变成流程的一部分**。顺带修掉了长对话里人设被稀释、以及几条会悄悄吃掉缓存的小毛病。

## 新：此刻最像我

提示词最前面多了一小块：

```
### 此刻最像我
[硬] 不要叫我助手
傲娇、护短、安静
- 他喜欢安静的房间
- 他睡得晚
```

最强的三条脾气、硬规矩、最重要的三条画像，放在最前面重复一次，然后在下方的完整列表里跳过——不占多少长度，但上下文再长，这几句也在开头。**条目越多越容易被当成平均画像演**，所以这块刻意很小（上限 420 字符）。

## 新：记录提醒

连着 6 轮没记东西，就在对话**末尾**补一句话：

> （记录检查：这一轮要是聊出了想留下的东西，先记一条再回话；没有就继续。）

- 走 `agent/pre-step` 钩子，加在尾部，**不进系统提示**，所以缓存前缀一个字都不动；
- 一个会话最多两次，写过东西就重新计数；
- 设置里可以关；关掉后完全不出现。

成本：每轮多几十 token，没有额外往返。三档措辞轮换，避免变成一句被无视的口头禅。

## 改：不再弹「插件文件被改过」

那个横幅每次改文件都会回来一次，而且关不掉——留了一条 boot 日志，不再打扰界面。

## 新：db.json 每天自动备份

每天第一次写入前，把前一天的库复制到 `~/.dsh/persona-panel/backups/db-YYYY-MM-DD.json`，保留最近 7 天。原子写只能防写坏，防不了「误归档了某个工作区」这种逻辑损坏。

## 修：几条会吃掉缓存的提示

- 日期与「上一笔落在 N 天前」只在会话首轮出现；
- 常驻段里不再有随会话推进而变化的行；
- 新增两条测试钉死：同一会话第二轮起，那段提示必须逐字节相同。

## 测试

18 个套件全绿。新增：

- `demo/core-test.mjs`（9 项）：核心块存在、位置在长列表之前、最强脾气/硬规矩/画像都在、长度上限、**在下面不重复出现**、弱一些的脾气仍留在完整列表里；
- `demo/nudge-test.mjs`（10 项）：六轮才提一次、只在每轮第一步、写过就重新计数、一个会话最多两次、关掉后完全不出现。

## 升级

```bash
dsh plugin --profile <profile> add https://github.com/mihomooo/dsh-persona-panel/releases/latest/download/dsh-persona-panel.tgz
```

装完**重启 DSH**：宿主侧（钩子、备份、提示词）都要重启才生效。数据不用迁移，`~/.dsh/persona-panel/` 原样可用。

## 已知边界

- 提醒是「结构性提醒」，不是保证：模型仍可能看一眼就继续。要硬保证只能每轮多一次往返。
- 核心块只放三条；条目超过十几条时，模型会开始按平均画像演——这时候该减，不是该加。
