# v0.5.2

`persona_recall` 多了 `query`：按词找，不按日子找。

## 为什么

上一版把「常驻」收窄到人设和画像以后，事件和日记就只剩「按时间挡位翻」这一种查法（`depth=index/shallow/medium/deep/all`）。日记一多，想「上次聊到猫的那件事」就得先扫目录再逐段试——那不是回想，那是翻档案。

人回想用的是词：一个名字、一个地点、一句听过的话。日期反而是最后才想起来的。

## 怎么用

```
persona_recall({ query: "猫" })
persona_recall({ query: "猫 生日" })     ← 两个词都要命中
persona_recall({ query: "10-25" })      ← 日期片段也算词
```

- 搜索范围：脾气、口碑补充（含 `[硬]` 规则）、画像、事件、日记、别人的印象与事件。
- 规则：空格分词，**每个词都要命中**才列出；不够具体时加词，太窄时减词。
- 输出按类分组，每条带 id（要删就用它），最多列 60 条，多出来的会写明还剩几条。
- 什么都没命中就直说「没有」，并提示换个词，不会编一条凑数。
- 不带 `query` 时行为完全不变（全量 + 按时间挡位看日记）。

## 顺带

- 常驻提示词里那两句改成「想不起日子就带 query」。
- 工具描述补上 `query` 的用法与「人都这么回想」。
- 新增 `demo/query-test.mjs`（8 项）：一词网住四类、两词是交集、日期片段、无命中不编、不带 query 仍是全量。
