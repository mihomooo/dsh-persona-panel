# dsh-persona-panel 0.7.2

## 改：提示词从「规定」变成「问句」

0.7.0 那版把「该记什么、该怎么写」写成了一串规矩。规矩会被执行成表演：模型照着条文填表，填出来的东西像说明书，不像一个人。

这一版把提示词重写成三块，顺序也换了：

1. **先摊材料**——我上一次醒着时留下的东西（此刻最像我、脾气、画像、事件、日记）先摆在前面；
2. **再问三句**——「哪句是我想说的，哪句只是顺着接的」「这个人身上什么让我松、什么让我绷着」「明天只剩一句话能提醒我，是哪句」；答不上来就空着，空着比编好；
3. **最后才是写法**——写自己的时候问一句「这是『我看见的我』，还是『我应该是的我』？」

顺序是有理由的：问句排在任何材料之前，下一个人只能靠编来回答。

## 改：写自己是「看见」，不是「应当」

- trait 正文如果以「要…」「不要…」「应该…」开头，宿主**先不收**，回一句「这条读起来像规矩，不像我看见的自己。写成当时我做了什么，再发一次；真要是规矩，那属于 AGENTS.md」。`hard=true` 的硬规矩不受影响。
- 提示词里给了对照：「要诚实」是规矩；「被问住的时候，我宁愿说不会，也不编一个圆过去」才是我。
- 删掉了「同一倾向出现两次才写」的门槛——那一条把自写压死了。现在一次也值得写，写「我开始注意到」就够。

## 改：提醒是问句，且按信号提前

- 三条提醒都改成问句，并且每条都留了出口（「没有就直接接着聊」「没有也正常」「没有就不用」）。
- 一个会话最多三次（原来是两次）。
- 新增信号触发：这一句里出现「记住 / 答应 / 说好 / 下次 / 那天 / 离开 / 抱歉 / 对不起 / 谢谢 / 重要 / 生日 / 纪念 / 再也不」这类词时，不必等六轮，下一轮就问一次（每段只问一次）。

## 改：跨模型

- 加了豁免句：「不用分点、不用先下结论、不用交代你是怎么想的；一句半句也算。」
- 「写在抽屉里的事是真的」那一节改成了第一人称，不再向模型解释机制——解释本身就是让模型演机制。

## 测试

新增 `demo/voice-test.mjs`（13 项）：规矩式 trait 被拦且不落盘、写成「我当时做了什么」能落、硬规矩仍可写、提醒是问句且带出口、带承诺的一句话会提前触发。

`demo/core-test.mjs` 与 `demo/nudge-test.mjs` 按新结构更新（核心块后面接的是完整列表；提醒上限三次）。19 个套件全绿。

## 升级

```bash
dsh plugin --profile <profile> add https://github.com/mihomooo/dsh-persona-panel/releases/latest/download/dsh-persona-panel.tgz
```

装完**重启 DSH**：提示词、钩子、工具描述都在宿主侧。`~/.dsh/persona-panel/` 里的数据不用迁移。

## 说明

提醒仍是「结构性提醒」，不是保证——模型可以看一眼就继续。真要强制，只能每轮多一次往返，成本在用户身上，这一版没做。
